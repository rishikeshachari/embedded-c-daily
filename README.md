# embedded-c-daily
Embedded C — Daily Practice

This repo tracks my daily progress through a self-study roadmap aimed at embedded engineering. Each folder (day01, day02, ...) contains that day's code and notes.

Roadmap (Days 1–13): C Fundamentals

Data types, variables, format specifiers
Operators and control flow
Functions and scope
Pointers
Bitwise operators
Structs
volatile and memory-mapped I/O concepts

Goal: build a solid C foundation before moving into microcontroller programming (registers, peripherals, RTOS).
